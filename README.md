# PPT全维度深度审查

它会沿着一条阅读因果链，审查整套 PPT：

**目标与任务 → 内容与证据 → 论证与页面链路 → 页面主旨与文字 → 视觉语义与版式 → 可读性、密度与节奏 → 中文表达与 AI 味 → 文件工程、可访问性与交付**

它会看：

- 这份 PPT 到底给谁看，要让对方理解、决定，还是行动；
- 数字有没有对象、时间、单位、统计口径和来源；
- 图表有没有把比较、流程、层级和因果关系画对；
- 观众能不能在 5 秒内找到这一页的主旨；
- 母版、布局、Logo、标题、字体和页脚有没有跨页漂移；
- 有没有溢出、重叠、字体替换、链接失效、不可编辑对象和文件交付风险。

并且会告诉你：哪里不成立，为什么，以及怎么改。

## 核心优势

- **八维度综合审查**：覆盖目标与任务、内容与证据、论证与页面链路、页面主旨与文字、视觉语义与版式、可读性/密度/节奏、中文表达与 AI 味、文件工程/可访问性/交付。
- **默认逐页深审**：快速索引只用于安排复核顺序，不用抽样代替逐页检查。
- **跨页一致性回归**：检查母版、布局、Logo、标题、字体、页眉页脚、页码和页面级覆盖，识别“看起来像同一套模板、实际发生漂移”的问题。
- **同页与跨页重复识别**：既检查同一页不同区域是否重复表达同一主张，也检查多页之间的标题、句式、总结和模板化表达是否重复。
- **通用保密审查**：涉外、对外发布、客户交流或外部共享时，逐页识别未公开、受限、可识别、可推断或组合暴露的信息，并定位到具体页面和对象。
- **证据驱动报告**：不输出泛泛的“可以更专业”，而是按八个维度列出问题、位置、证据、建议和严重度/置信度。

## 使用方式

将本目录作为 Codex skill 使用，或在 Codex 中直接调用：

```text
$presentation-deep-review 审查这份 PPT
```

开始审查前，技能会询问：

1. 受众：谁会看；
2. 使用场景：现场讲解、线上汇报、会前预读、会后独立阅读等；
3. 时长：预计总时长；
4. 审查范围：综合审查，或选择一个/多个专项维度；
5. 可选补充：品牌/母版规范、字体/层级要求、保密要求或重点担忧。

用户也可以跳过咨询，按默认范围直接开始。默认范围是八个维度、逐页深审。

## 输入与输出

支持的输入包括：

- `.pptx`：可检查文本、备注、对象、几何、母版、布局、链接、隐藏内容、文件包和渲染结果；
- `.pdf`：可检查可提取文本与页面渲染，但不声称检查原生母版、备注或 OOXML 对象；
- 逐页截图：可检查可见文字、视觉层级、语义、密度和一致性；
- 大纲或讲稿：可检查目标、内容、论证、页面主旨和中文表达。

报告只保留有证据的问题，不输出优点清单、总分、逐页流水账或单独的修改顺序。每条问题包含：

- 问题
- 位置/范围
- 证据
- 建议
- 严重度/置信度

## 保密审查说明

当用户声明涉外、对外发布、客户交流、外部共享、公开演示或保密审查时，自动启用第八维度的对外展示敏感性检查。判断依据包括：

- 信息是否有可靠公开来源；
- 是否受权限、合同、法规或客户约定限制；
- 是否能识别具体人员、组织、项目、产品或系统；
- 是否能推断未公开状态、规模、性能、成本、策略或路线图；
- 是否存在精确值、组合暴露或交付非必要信息。

保密报告必须定位到页码和对象。普通敏感事实、指标、名称、案例或技术描述默认可以引用原值帮助回查；用户要求打码时按要求处理。密码、私钥、令牌、会话凭据等认证材料始终不回显完整值。

## 证据准备与效率

PPTX 审查建议先运行：

```bash
python3 scripts/build_evidence.py input.pptx evidence/
```

脚本生成：

- `evidence.json`：完整结构和对象证据；
- `system-matrix.json`：母版、布局、主题、标题和重复构件统计；
- `review-index.json`：输入文件哈希、缓存信息、异常页、隐藏内容和需要深审的对象；
- `slide_text.txt`：按页汇总的文本和备注。

`review-index.json` 只用于定位异常和复用证据，不能替代全量逐页深审。
