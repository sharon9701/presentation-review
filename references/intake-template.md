# PPT 审查启动咨询模板

本文件供 `presentation-review/SKILL.md` 在正式审查前读取。它定义用户可见的提问、维度简述、自然语言映射、默认值和确认方式；不替代八个维度的详细审查规则。

## 用户可见模板

以下文案须原样发送；不要恢复“目的与期望结果”提问，也不要自行增加问题。

```markdown
开始前，请提供相关信息，以便进行更全面、高效的审查；您也可跳过此步骤，直接开始。
一.受众：谁会看？（角色/层级/人数）
二.使用场景：现场讲解、线上汇报、会前预读、会后独立阅读等
三.时长：预计总时长
四.审查范围：  
综合审查（八个维度，默认）  
专项审查（选择一个或多个，给出序号）
1.目标与任务：是否契合对象和任务
2.内容与证据：数据和结论是否可靠
3.论证与页面链路：逻辑是否连贯
4.页面主旨与文字：重点和文字是否清楚
5.视觉语义与版式：图文布局是否传意
6.可读性、密度与节奏：是否易读、不拥挤
7.中文表达与 AI 味：是否自然、具体、少套话
8.文件工程、可访问性与交付：文件是否可打开、稳定可交付

可选补充：品牌/母版规范、字体/层级要求、保密要求或重点担忧。
受审查维度及内容复杂度影响，审查可能需要费点时间，请耐心等待。
```

用户可直接回复“开始”“按默认”或“跳过，直接开始”；如果上文已经提供完整信息，先回显识别结果，不重复提问。

也可接受一行回复：

```text
受众=；场景=；时长=；范围=综合/专项（维度序号）；约束=；保密审查=开启/未指定；重点担忧=。
```

咨询中不单独询问“目的与期望结果”。技能从 PPT 的封面、标题、备注、页面链路和已有上下文推断沟通任务；推断不足时在内部记录 `Needs confirmation`。

### 保密触发映射

- “涉外”“对外发布”“客户交流”“外部共享”“保密审查”“检查敏感信息” → `confidentiality_review=enabled`。
- “仅内部使用”“无需保密审查” → `confidentiality_review=not_requested`；仍进行常规隐私和残留扫描。
- 未提及 → `confidentiality_review=needs_confirmation`；若材料或交付描述出现外部共享线索，先在确认回显中提示。
- 保密审查不是第九个维度，统一归入“八、文件工程、可访问性与交付”。

## 解析与默认规则

| 用户回答 | 内部设置 |
|---|---|
| 未填写范围、说“全面/综合/全部”、或只说“审查 PPT” | `review_scope=all`，选择八个维度 |
| 明确列出一个或多个维度 | `review_scope=selected`，只输出所选维度 |
| 说“只看排版/视觉” | 映射为“视觉语义与版式”+“可读性、密度与节奏”，并在确认回显中明确列出 |
| 说“看母版/Logo/字体/统一性/导出” | 选择“文件工程、可访问性与交付” |
| 说“看逻辑/结构/顺序/故事线” | 选择“论证与页面链路” |
| 说“看数据/来源/可信度/口径” | 选择“内容与证据” |
| 说“看标题/文案/文字/主旨” | 选择“页面主旨与文字” |
| 说“去 AI 味/中文自然/少套话” | 选择“中文表达与 AI 味” |
| 说“目标/受众/任务是否清楚” | 选择“目标与任务” |

自然语言同时命中多个维度时全部保留，并在确认回显中列出；用户明确说“只看某一项”时，不擅自扩展为全部维度。

## 专项审查的前置依赖

专项审查只限制最终报告的输出范围，不等于跳过必要取证：

- 所有 PPTX 都必须先完成最低限度的文件可读性、页数、渲染和跨页系统预检；只报告与所选范围相关的结果。
- 判断“视觉语义与版式”或“可读性、密度与节奏”时，可内部读取页面主旨、页面链路和文本证据，但不输出未选维度的问题。
- 判断“页面主旨与文字”时，可内部读取内容证据和页面任务；判断“文件工程、可访问性与交付”时，可内部读取渲染和对象证据。
- 若用户选择的维度依赖未提供的背景，继续检查可观察事实，并把背景依赖标为 `Needs confirmation`。

## 确认回显

用户回答后，先用自然语言回显，不要求用户填写 JSON：

```text
已识别：
受众=管理层｜场景=现场讲解｜时长=30 分钟｜范围=综合审查｜重点=版式统一｜约束=沿用现有母版｜保密审查=未指定。
缺失或待确认：目标播放设备、数据来源。
是否按以上设置开始审查？
```

确认回显中，只有用户提到或材料显示存在外部共享线索时保留 `保密审查=已开启/待确认/未指定`；不要将未提出保密要求的普通业务信息直接标成机密。

用户回复“开始”“确认”或“按默认”即可进入证据准备。若用户只修改某个字段，只更新该字段并再次回显，不重复询问已确认项；最多追加一轮会改变结论的追问。

## 缺失信息处理

- `audience`、`delivery_mode`、`duration_minutes`、`constraints` 未提供时记为 `unknown`。
- 受众和任务相关信息优先从封面、目录、备注、标题链和页面内容推断；推断结论标 `Needs confirmation`。
- 缺少场景或时长时，仍可进行静态内容、结构、视觉和文件检查；涉及观看距离、现场节奏或时间负荷的结论标 `Needs confirmation`。
- 不因为用户没有回答咨询就生成空泛问题，也不把缺少背景本身当成 PPT 缺陷。
