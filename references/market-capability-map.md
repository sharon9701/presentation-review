# 市场能力与审查维度映射

本文件用来说明总控与八个维度模块吸收了哪些公开能力。参考项目是方法来源，不是运行时依赖；详细可执行规则以各维度的 `SKILL.md` 为准。

## 参考项目

### Anthropic PPTX skill

来源：[anthropics/skills](https://github.com/anthropics/skills)

吸收的核心做法：在判断或编辑前先提取页面文本和结构对象，对所有页面渲染，分开检查源文件和观众实际看到的结果，留意溢出、重叠、占位符、空页和文件包关系。

主要落点：

- 总控的统一证据包和输入能力声明；
- 文件工程、可访问性与交付模块的文件包、渲染和几何检查；
- 视觉与密度模块的观众实际阅读检查。

### `mpuig/agent-slides`

来源：[mpuig/agent-slides](https://github.com/mpuig/agent-slides)

吸收的核心做法：用页面功能和叙事流检查单页是否在推进观众理解，使用结论型标题、使视觉形式匹配内容关系，同时检查信息密度、可扫读性和版式重复。

主要落点：

- 论证与页面链路：页面角色、依赖、跳跃和假进展；
- 页面主旨与文字：结论型标题、主信息清晰度，以及同页不同区域的语义冗余识别；
- 视觉语义、可读性、密度与节奏：关系编码和非必要重复。

### `dmmdea/humanize-presentations`

来源：[dmmdea/humanize-presentations](https://github.com/dmmdea/humanize-presentations)

吸收的核心做法：把“AI 味”当作语言、页面结构和作者信息共同形成的模式，不抓一个词定性；检查重复 chrome、泛化章节标题、公式化卡片、可互换总结，并区分讲稿备注与页面可见文案。

主要落点：

- 中文表达与 AI 味：抽象黑话、重复句式、丢失主体与边界、模型残留；
- 页面主旨与文字：讲稿直贴、标题泛化和页面文字的信息粒度；
- 可读性、密度与节奏：重复布局、模板化 chrome 和过度机械的页面簇。

### `wshobson/agents` PPTX quality gates

来源：[wshobson/agents](https://github.com/wshobson/agents)

吸收的核心做法：检查几何边界、对象重叠、对比度、替代文本、阅读顺序、颜色编码、原生可编辑性和 OOXML 关系，并把来源链路追溯到具体论断或图表。

主要落点：

- 内容与证据：论断、口径、来源和限定语的对应；
- 视觉语义与版式：几何、对齐、裁切、图表标注和颜色语义；
- 文件工程、可访问性与交付：包完整性、渲染、原生对象、辅助阅读、可维护性，以及按公开性/受限性/可识别性/可推断性/组合风险判断对外敏感内容。

### `fliingelephant/agentic-audit`

来源：[fliingelephant/agentic-audit](https://github.com/fliingelephant/agentic-audit)

吸收的核心做法：将 Form、Flow、Content、Pacing 视为相关但不同的审查面，优先找到系统性根因，把重复局部意见合并，用严重度区分阻断问题与润色问题。

主要落点：总控的模块调度、边界定义、证据归并、跨页模式合并、严重度和置信度。

## 落地表

| 能力 | 主要落点 | 最终产物 |
|---|---|---|
| 目标、受众、行动 | 任务、取舍、交付方式 | 目标与任务模块 |
| 论断、口径、来源 | 数字、因果、比较、引用 | 内容与证据模块 |
| 叙事流、页面角色 | 依赖、跳跃、假进展 | 论证与页面链路模块 |
| 结论型标题、页面文字 | 一眼主旨、文字粒度、备注分工 | 页面主旨与文字模块 |
| 同页语义冗余 | 标题、分区、卡片、图示、总结之间是否重复同一主张且没有信息增量 | 页面主旨与文字模块 |
| 视觉编码、模板 | 比较、流程、层级、对齐 | 视觉语义与版式模块 |
| 扫读、密度、节奏 | 字号、注意力、重复、观看距离 | 可读性、密度与节奏模块 |
| 去 AI 味 | 具体主体、动作、结果、边界、作者信息 | 中文表达与 AI 味模块 |
| 文件、可访问、可编辑 | 渲染、几何、包关系、辅助阅读 | 文件工程、可访问性与交付模块 |
| 对外展示敏感性 | 逐页识别任意未公开、受限、可识别、可推断或组合暴露的信息，并按用户授权决定原值引用 | 文件工程、可访问性与交付模块 |

## 不照搬的做法

- 不强制建立 PPT 类型表或固定叙事模板；
- 不要求每个标题都改成结论句；
- 不以单一评分、AI 检测器或个人审美作为结论；
- 不因缺少来源就定性为造假，先报告证据缺口；
- 不通过错别字、俗语、虚构经历来伪造“人味”；
- 不把外部项目当作运行时必须安装的依赖。
